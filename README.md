# Sathi — Care Coordination (PWA)

A React + Vite progressive web app for coordinating medication, inventory,
purchases and transport for a shared care plan.

## Scripts

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server (PWA service worker enabled) |
| `npm run build` | Production build, including service worker + manifest (`dist/`) |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
| `npm test` | Run unit tests once (Vitest) |
| `npm run test:watch` | Run tests in watch mode |
| `npm run generate:icons` | Regenerate the PWA icon set from the inline SVG source |

## PWA setup

- **Manifest** — single source of truth in `src/pwa/manifest.js`, consumed by
  `vite.config.js` (`vite-plugin-pwa`) and validated by `src/pwa/manifest.test.js`.
- **Icons** — generated by `scripts/generate-icons.mjs` (sharp) into `public/`:
  `icons/icon-192.png`, `icons/icon-512.png`, `icons/icon-512-maskable.png`,
  `icons/apple-touch-icon.png`, plus `favicon.svg`, `favicon-32x32.png`,
  `favicon-16x16.png`. Edit the SVG in the script and re-run
  `npm run generate:icons` after changing the artwork.
- **Service worker** — `generateSW` strategy with `registerType: 'autoUpdate'`,
  precaching of the build output and runtime `CacheFirst` caching for images
  (30 days) and fonts (1 year). `devOptions.enabled` lets you test the SW in dev.
- **HTML meta** — `index.html` carries `theme-color`, `apple-mobile-web-app-*`
  and favicon/apple-touch links.

## Testing & CI/CD

- **Tests** — Vitest + Testing Library (jsdom). `src/App.test.jsx` covers a
  render/interaction smoke test; `src/pwa/manifest.test.js` validates the
  manifest and the actual PNG icon files (signature + pixel dimensions).
- **Pre-push hook** — `simple-git-hooks` installs a git `pre-push` hook
  (configured in `package.json`) that runs `npm run lint && npm test`, so a
  failing test **blocks the push**. Hooks are (re)installed automatically on
  `npm install`. Escape hatch (not recommended): `SKIP_SIMPLE_GIT_HOOKS=1 git push`.
- **CI pipeline** — `.github/workflows/ci.yml` runs on every push and pull
  request: `npm ci` → `npm run lint` → `npm test` → `npm run build`, then
  uploads the `dist/` bundle as a build artifact.
